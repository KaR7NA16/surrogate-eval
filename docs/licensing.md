# Licensing scope

The root MIT license covers the generic package under `src/`, its tests, generated-example implementation, scripts and project documentation. Third-party dependencies and cited articles retain their own terms.

Historical research data, model weights, protocols and source snapshots are not included in this repository or its wheel/source distributions. The root MIT grant does not relicense an external evidence bundle. Its manifest establishes byte identity, not ownership or redistribution rights.

Dependencies are installed separately and are not vendored into this package. No external paper text or third-party library source is included as new project code.
