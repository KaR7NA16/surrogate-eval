# Changelog

## 0.1.0 — 2026-09-12

- Introduced a standalone NumPy package and `rfl` CLI with versioned physical paired-output records.
- Added nominal/response scoring, equal-cluster comparisons, descriptive paired bootstrap intervals and exploratory scalar decision metrics.
- Added optional local geometry/noise diagnostics and a train/validation fixed-feature ridge baseline.
- Added independent linear and nonlinear pendulum examples, tests, packaging and CI configuration.
- Preserved the original L96 study as an optional hash-verified reproduction case with explicit scientific limits.

This is a local alpha release; no public publication or remote CI execution is asserted.
